# 2026-11-05

## 截图功能改为网页框选区域截图

- 原先 `captureVisibleTab` 直接抓整屏可见区域；改为「网页内拖拽框选 → 只截选区」。
- 新增 `edge/content/crop.js`：由 `chrome.scripting.executeScript` 注入（不在 manifest 的 content_scripts 里），
  用全屏遮罩 + Shadow DOM 做框选，结果经 `sp-crop-done` / `sp-crop-cancel` 广播回传 CSS 像素选区、
  视口尺寸与 DPR；遮罩与扩展自己的悬浮栏（page.js 里加了 `sp-selection-bar` / `sp-launcher-rail` id）
  在截图前隐藏，避免被截进图片。
- `edge/sidepanel/sidepanel.js`：新增 `screenshotTab`（全页模式下激活最近网页标签）、`selectArea`
  （临时消息监听 + 超时 + 注入失败提示）、`cropShot`（按截图实际像素与视口比例换算，canvas 裁剪）；
  `addImageAttachment` 改为返回布尔；勾选截图插件后点发送若取消/失败则中止发送并保留输入。
- 文案与 README 同步为「框选截图」。
- 验证：`tests-web/verify-crop-sim.mjs` 离线仿真 12 项全通过；`tests-web/verify-crop-shot.mjs`
  为 CDP 真机回归脚本（需浏览器开 9333 调试端口，本次调试浏览器已关闭，未跑真机）；
  `tests-web/verify-docked.mjs` 第 5 步改为模拟拖拽。
- 待办提醒：`deploy/dist/extension-0.1.0` 与 `sp-extension-0.1.0.zip` 是旧发布快照，
  发布时需重新打包并包含新增的 `content/crop.js`；本地生效需在扩展管理页重新加载 `edge/`。
